지금 화면은 **메시지는 명확하지만, 전환(회원가입/체험)과 신뢰 전달이 약한 구조**입니다. 특히 “의료/인지케어” 분야는 **신뢰·전문성·데이터 기반**이 핵심이라, 그걸 시각적으로 더 강하게 보여줘야 합니다.

아래는 **실제 개선하면 효과 바로 나는 디자인 방향**입니다.

---

# 1️⃣ 히어로 섹션 (첫 화면) — “좋은데, 아쉽다”

현재:

* 메시지: 좋음 (인지 케어 플랫폼)
* 문제:
  → “왜 써야 하는지”가 약함
  → 시각 요소 부족 (텍스트 중심)

### 개선안

👉 **텍스트 + 시각 + 신뢰 3요소 구조로 변경**

**좌측 (텍스트)**

```
뇌건강을 위한 인지 케어 플랫폼
→ 6개월 내 인지기능 저하 위험 예측 & 맞춤 훈련 제공

✔ AI 기반 인지 평가
✔ 개인 맞춤 훈련 프로그램
✔ 전문가 검증 콘텐츠
```

**우측 (비주얼)**

* 뇌 이미지 ❌
* 👉 “실제 사용 화면 UI” (훨씬 중요)

예:

* 인지 점수 그래프
* 훈련 화면
* 리포트 결과

👉 “서비스가 어떻게 보이는지” 보여줘야 신뢰 상승

---

# 2️⃣ CTA 버튼 구조 (전환 핵심)

현재:

* 무료 체험 시작하기
* 서비스 소개

👉 방향은 맞지만 약함

### 개선안

👉 **Primary / Secondary 명확히**

* 🔵 무료 인지검사 시작하기 (강조)
* ⚪ 결과 샘플 보기 (신뢰 강화용)

👉 “서비스 소개”보다
👉 “결과 예시”가 훨씬 클릭됨

---

# 3️⃣ 신뢰 영역 추가 (이거 없으면 의료서비스 느낌 안남)

히어로 아래 바로 넣기

### 추천 구성

```
✔ 의료진/전문가 참여
✔ 임상 기반 알고리즘
✔ 사용 기관 수 / 사용자 수
```

예:

* 5,000+ 사용자
* 20+ 협력 기관
* 신경과 전문의 개발

👉 이건 conversion에 **가장 영향 큼**

---

# 4️⃣ 서비스 구조 섹션 (현재 없음)

지금 사이트는 “뭘 제공하는지” 흐름이 부족함

### 추천 UI: 3단계 구조

```
1. 검사
AI 인지 평가 (5~10분)

2. 분석
인지 위험도 + 영역별 점수

3. 훈련
개인 맞춤 프로그램 제공
```

👉 아이콘 + 카드 UI 추천

---

# 5️⃣ 타겟 분리 (핵심 개선 포인트)

지금은 대상이 애매함

👉 반드시 분리해야 함

### 예시

```
👵 개인 사용자
→ 내 인지 건강 체크

👨‍⚕️ 전문가 / 기관
→ 환자 관리 및 교육

👨‍👩‍👧 보호자
→ 가족 상태 모니터링
```

👉 클릭형 카드 UI로 구성하면 좋음

---

# 6️⃣ 실제 화면 미리보기 (가장 중요)

👉 지금 사이트에 **없으면 거의 실패 수준**

반드시 추가:

* 검사 화면
* 결과 리포트
* 훈련 콘텐츠

👉 “텍스트 설명”보다 10배 효과
